# Portfolio — Oumar Farouk Mahaman Habibou

Vue 3 + Vite. Hébergement gratuit sur Vercel.

## Lancer en local
    npm install
    npm run dev

## Ajouter ta photo
Dépose ta photo dans `public/photo.jpg` (portrait, idéalement 800 × 1000 px). Sans photo, un monogramme « OF » s'affiche.

## Modifier les textes
Tout le contenu (FR + EN) est dans `src/content.js`.

## Déployer
Pousse sur GitHub, puis sur Vercel : Framework Preset = Vite (détecté automatiquement).
